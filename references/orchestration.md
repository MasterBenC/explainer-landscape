# 多技能统筹：谁负责什么

一条横版解说片通常不只用一个技能。这张表是分工，不重复造轮子；只用本技能也能出片，其余按需接入。

| 技能 | 它真正提供的 | 在这条片子里负责 |
|---|---|---|
| `rea-video` | 逐镜取证（实拍/AI/3D/代码）、报错、拆片包 | 拆参考片，拿到版式、字号、节奏的**测量值** |
| `explainer-landscape`（本技能） | 版式规范 + 帧渲染器 + 自检 | 分镜 spec、逐帧渲染、横条/页眉/标注、成片组装 |
| `koubo-animation-pipeline` | 节拍纪律 + 五道验收 + 版式单一真源 | **节拍跟台词走**、验收阈值、不许写死坐标 |
| `deepseek-opus-motion-skill` | 三本账（规格/变形/元素）+ 图层表 + 五人评审 | 写 spec 之前先列元素清单和图层顺序；交付前自评 |
| `lemo-opuscar`（99 风格） | 每种风格的 STYLE.md：材料、版式、动效语法 | 定风格：Visual Investigation（时钟/证据/不确定）、Newsreel（旧素材+锐文字）、News Package（横条/rundown） |
| `video-shotcraft` | 152 张镜头配方 + Remotion 组件 + 音效库 + 剪映导出 | 需要"真正的运动设计"时换渲染层：镜头级动效、2.5D 运镜、卡点 |

## 一条片子该怎么串

```
① 选题 → 口播稿（人写）
② rea-video 拆参考片          → 测量值：版式/字号/节奏/转场配比
③ lemo 选风格                → STYLE.md：材料、色彩、动效语法
④ opus-motion 三本账         → 元素清单 + 每镜图层表（背景/中景/前景）
⑤ explainer-landscape 写 spec → 版式 + 槽位 + beats
⑥ 渲染                        → 两条路：
   a. 本技能 PIL 渲染器（快、可控、无依赖）
   b. video-shotcraft 的 Remotion 组件（动效上限高、可导剪映）
⑦ koubo 五道验收              → 越界/重叠/字幕带/画布利用/节拍
⑧ 混音 + 字幕 + 出片
```

## 什么时候该换渲染层

PIL 渲染器的上限很清楚：**能做位移、透明度、遮罩、缩放，做不了真 3D、弹簧物理、粒子、逐字排版的高级效果**。

判据：如果参考片里的动效包含下面任意两条，就该上 Remotion（video-shotcraft 的组件）：

- 元素沿曲线运动或带过冲（spring）
- 画面有透视/景深/2.5D 运镜
- 文字逐字或逐词编排（kinetic typography）
- 转场是"材质变化"（撕纸、液态、故障）
- 需要卡音乐节拍做缩放/闪白

反之，信息图 + 数据卡 + 图片 + 横条这套，PIL 足够，而且改一版只要 20 秒。
