# 版式参数（1920×1080）

全部数值由一条 4:17 的财经调查解说逐镜测量后换算：原片 960×544，乘 2 得 1080p 坐标；字号按字框高度反推，实际渲染时可 ±2px。

## 画布

| 项 | 值 |
|---|---|
| 尺寸 | 1920×1080 |
| 帧率 | **30fps 优先**，由 spec 的 `canvas.fps` 指定（缺省按 30 兜底）；24/25fps 只在素材本来就是那个帧率时用 |
| 底色 | `#07080A` |
| 安全区 | 四周 64px；实际内容边距见下 |
| 内容左边界 | 134 |
| 内容右边界 | 1786 |
| 内容宽度 | 1652 |

| token | 值 | 用途 | 用量上限 |
|---|---|---|---|
| `bg` | `#07080A` | 背景 | 全屏 |
| `text` | `#F2F2F2` | 主标题、巨数字、字幕 | — |

| `dim` | `#6C7177` | 免责声明、时间码 | — |

## 固定 chrome（常驻图层）

坐标是**左上角**，字号为 px，行高 1.35。

| 元素 | x | y | 字号 | 颜色 | 内容 |
|---|---|---|---|---|---|
| 章节牌 | 134 | 96 | 60 bold | text | `线索一·爆料的媒体`；`·` 用 accent |
| 品牌水印 | 1786（右对齐） | 106 | 34 | muted | 账号/机构名，只在章节段出现 |
| 日期戳 | 134 | 176 | 40 | text | `11-09`，等宽数字 |
| 相对时间 | 134 | 248 | 30 | muted | `两天前` / `今天早上` |
| 主标题 | 134 | 310 | 64 | text | 一屏一句，最多 14 字 |
| 副标题 / 署名（`kicker`） | 134 | 410 起（跟随标题：单行标题在 410，两行标题在 493） | 28 | muted | `黄仁勋·英伟达创始人、CEO` |
| 横条（`strap`） | 134 | 812（基线居中） | 34 bold | text | `贷款 1700 亿，产业债每年 150 亿。`，右端可挂 `clock` |
| 来源行 | 134 | 884 | 21 | dim | `画面：CNBC（2026-11-09）`，以「画面：」开头 |
| 字幕 | 134 | 1000（基线） | 54 | text | 单行；两行时首行上移到 930 |
| 免责声明 | 134 | 1012 | 20 | dim | `本视频引用的研究与数据均标注出处`（`disclaimer`，默认 true） |
| 时间码 | 1746（右对齐，即 `RIGHT−40`） | 1006（基线） | 19–20 mono | dim | `TC 00:04.0`，需要 `show_tc: true` |

规则：
- 上表是**档案档**的全量坐标；走极简档时只留 `chapter` + `subtitle`，
  其余 chrome（日期戳、相对时间、来源行、时间码、横条、免责）全部不画，
  见 `chrome-presets.md`。极简档底部 130px 只有字幕。
- 字幕两行时，免责声明隐藏（原片实测：第二行字幕会占掉 y≈0.94 那一行）。
- 时间码每镜更新，格式 `TC mm:ss.s`；只有 `show_tc: true` 且写了 `tc` 才画。
- 来源行只写"机构 + 日期 + 素材类型"；不缩字号，按 21px 自动折行（最多两行，超两行请精简文案）。
- 章节牌出现的那一镜，品牌水印同时出现；其余镜头水印隐藏。
- 坐标以 `render.py::draw_chrome` 为准：改代码要同步这张表，别只改文档。

## 字号阶梯

| 级别 | 字号 | 用途 |
|---|---|---|
| display | 150–180 | 巨数字（`17年`、`$2500万`） |
| H1 | 88 | 结论大字、结尾结语 |
| H2 | 64 | 主标题（章节牌是 60，见上面 chrome 表与 `kit_chrome.py:29/35`） |
| H3 | 42 | 引文标题、卡片标题 |
| body | 30 | 条目正文、副标题 |
| sub | 21–24 | 来源、注解 |
| micro | 20 | chrome |

一条画面里最多用三级；`display` 一屏只能有一个。

## 左栏信息栈

原片的左侧是一个固定栈，从上到下：

```
y=96    章节牌 / 媒体名（60px）
y=176   日期（40px）
y=248   相对时间（30px，muted）
y=310   主标题（64px，最多两行）
y=410   副标题/署名（28px，muted；标题两行时下移到 493）
y=450+  条目区（30px，逐条出现，行距 1.6）
y=812   横条（34px，可选，不属于信息栈，压在最下层）
```

条目区最多 4 条；超过 4 条拆成两镜。

## 栅格

12 栏，栏宽 123，间隔 16，起于 134 止于 1786（12×123 + 11×16 = 1652 = 内容宽度，见上表）。
第 n 栏左边界 = `134 + (n−1) × 139`。

| 用途 | 占用 | 像素 |
|---|---|---|
| 左栏（文字） | 1–5 栏 | 134–813 |
| 单栏通栏 | 1–12 栏 | 134–1786 |
| 左画面 + 右证据 | 左 1–6 / 右 7–12 | 134–952 / 968–1786 |
| 巨数字居中 | 4–9 栏 | 551–1369 |
| 关系图 | 2–11 栏 | 273–1647 |

栅格只是对齐基准：具体版式的卡片框在 `kit_forms.py` 里按版式微调（例如 `evidence` 实测用
左 134–900 / 右 960–1786；右框起点 960 比第 7 栏的 968 早 8px，是为了让引文与 `attrib` 对齐）。
