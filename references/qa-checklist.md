# 交付前自检清单

跑 `python "<skill-dir>/assets/kit/audit.py" spec.json` 会自动查表里的「机器可查」项；有静帧时加
`--images out/` 再查红占比、填充率、亮度。其余靠人眼过一遍。

## 一、版式

| 检查 | 判据 | 机器可查 |
|---|---|---|
| 安全区 | 所有文字在 x 134–1786 之间，y 96–1040 | 部分 |
| 底部保留区（档案档） | y > 860 只放字幕、来源、免责、时间码 | 部分 |
| 底部保留区（极简档） | **y > 860 只有字幕**；来源/免责/时间码/横条一个都不许进 | ✓ |
| 一屏一论点 | 每镜只有一个主标题，条目 ≤ 4 | ✓ |
| 字号不越级 | 一屏最多三级字号；display 只有一个 | ✗ |
| 红色用量 | 单帧红色 < 2% 像素（一个数字或一个分隔符） | `--images` |
| 图片不压字幕 | 图片下沿 ≤ 820（贴底抠像 ≤ 860） | ✗ |

## 二、节奏

| 检查 | 判据 | 机器可查 |
|---|---|---|
| 每分钟刀数 | 8–14 | ✓ |
| 镜长交替 | 不出现连续 6 镜都在 2–5s | ✓ |
| 版式交替 | 不出现连续 3 镜同版式 | ✓ |
| 章节数 | 3–5 个（4 分钟片；`audit.py` 在 ≥12 镜时查上下界） | ✓ |
| 长短比 | 长镜（>10s）占 15–25%，短镜（<2s）占 15–30% | 部分 |
| 素材镜间隔 | 每 3–4 个排版镜后插 1 个素材镜 | ✗ |

## 三、内容可信度

| 检查 | 判据 | 机器可查 |
|---|---|---|
| 每张截图有出处 | 来源行写清机构 + 日期，不写"网络" | 部分 |
| 每个数字有单位 | 数字卡出现"17年""$2500万"，不出现光秃秃的"17" | ✓ |
| 每个数字有注解 | `note` 或 `caption` 至少一个 | ✓ |
| 引述有归属 | 引文下必须有 `attrib`（机构·日期） | ✓ |
| 结论有来源 | `sources` 版式的 `blocks` 覆盖全片引用 | ✓ |
| 来源页位置 | `sources` **必须是最后一镜**，后面不许再有镜头 | ✓ |

## 四、动效

| 检查 | 判据 | 机器可查 |
|---|---|---|
| 出现时长 | 0.25–0.45s；`instant` 占三分之一 | 部分 |
| 逐条间隔 | 1.2–2.4s，和旁白念到那条对齐（±0.15s） | ✗ |
| 转场不连用 | 同一转场不连续出现三次 | ✗ |
| 转场时长 | `transition.duration < dur`，常规 0.35–0.6s | ✓ |
| 字段拼写 | `motion` 只认 `item`/`at`/`dur`/`ease`；`ease` 只认 `out`/`in_out`/`instant`/`linear` | ✓ |
| 无禁区动画 | 无 Ken Burns（`camera` 未开或 ≤0.012）、无粒子、无 bounce；`count: true` 未经允许不出现 | ✓（部分） |

## 五、成片回看（人工）

按顺序看三遍：

1. **静音看**：每一屏能不能只看画面就知道在说什么？不能就说明标题或数字不够硬。
2. **只听声音**：逻辑是否连贯？中间断掉的地方，往往是画面比信息跑得快。
3. **抽帧拼图**（`render.py --contact`）：整片版式是不是"一排都是一样的双栏"？是就换版式。

## 六、常见返工点

| 症状 | 原因 | 改法 |
|---|---|---|
| 看着像 PPT | 每屏都是标题 + 图 | 加 `bignum` 和 `relation`，让数字和图承担信息 |
| 看着像短视频 | 动效太花、背景有渐变 | 关掉所有背景动画，动效只留 appear/change |
| 看不下去 | 连续 20 秒没有新信息 | 拆镜，或在该镜里加 2 个揭示节拍 |
| 不可信 | 截图太小 / 没有出处 | 裁到关键块放大，来源行写全 |
| 节奏平 | 全部 3–5 秒 | 插 1.2 秒的证据闪插，和 15 秒的数据卡 |
