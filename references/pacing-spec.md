# 节奏与结构

## 实测基线（4:17 片，48 镜）

| 指标 | 数值 |
|---|---|
| 总时长 | 257.5s |
| 镜头数 | 48 |
| 平均镜长 | 5.4s |
| 中位镜长 | 3.2s |
| 最短 | 0.46s |
| 最长 | 23.4s |
| 每分钟切镜 | 11.2 刀 |
| 转场构成 | 硬切 50%、闪白/黑场 15%、划像 15%、虚焦 12%、叠化 8% |

镜长分布是**两极**，不是正态：

| 区间 | 数量 | 作用 |
|---|---|---|
| < 2s | 12 | 证据闪插、状态切换（"两天前"→"今天"） |
| 2–5s | 17 | 单个论点 + 一张证据 |
| 5–10s | 9 | 论点 + 两三个证据轮换 |
| > 10s | 10 | 数据卡、逐条揭示、关系图、来源清单 |

规则：**长短必须交替**。连续三镜都在 2–5s 会显得平；连续两镜超过 15s 会显得拖。

## 五幕结构（按 4 分钟片校准）

| 幕 | 时间 | 内容 | 画面手法 |
|---|---|---|---|
| 冷开场 | 0:00–0:03 | 用一句话 + 一个矛盾开场（"他卸任了，但董事会两天前还说信任他"） | 大字标题 + 人物卡 / 新闻页，1–2 镜 |
| 时间线铺垫 | 0:03–0:17 | 用日期戳快速推进：两天前 → 今天早上 | 日期戳 + 证据闪插，每镜 1–2 个日期 |
| 转折 | 0:17–0:38 | 事件落地（辞职、罢免、数字） | 巨数字卡 + 声明截图 |
| 提问 | 0:38–0:47 | 把观众的问题说出来："背后的推手，到底有谁？" | 关系图（空）或纯文字卡 |
| 线索段 ×3 | 0:47–2:00 | 每条线索 30–40s，含 2–4 个子论点 | 章节牌 + 双栏证据 + 逐条揭示 |
| 后果与受益 | 2:00–2:55 | 谁得利、代价是什么 | 巨数字卡 + 时间轴对比 |
| 反证 | 2:55–3:45 | 主角其实也下了注（游说费、捐款） | 时间轴 + 关系图 |
| 结语 + 来源 | 3:45–4:17 | 一句收束 + 全部出处 | 结语大字 + 来源清单 |

比例：开场 3%、铺垫 5%、转折 8%、提问 4%、线索 45%、后果 22%、反证 13%、收尾 12%。

## 章节牌的使用

- 每条线索开头打一次章节牌（`线索一·爆料的媒体`），停留到该节结束（约 30–40s），不闪烁。
- 章节牌出现时同步出现品牌水印；章节结束时一起消失。
- 全片 3–5 个章节；少于 3 个说明结构没搭起来，多于 5 个说明分段太碎。

## 一镜的信息量

| 版式 | 一镜最多 |
|---|---|
| `bignum` | 1 个数字 + 1 句解释 |
| `evidence` | 1 张主证据 + 1 句引文 |
| `list` | 4 条 |
| `timeline` | 4 个点 |
| `relation` | 5 个卫星节点 |
| `sources` | 20 行 |

超过就拆镜。**一屏两个论点 = 观众两个都没记住。**

## 与旁白的对齐

- 每镜开头 0.3s 内必须出现该镜的关键信息（数字或标题），不要等旁白念到才出现。
- 证据截图的出现时间 = 旁白说出机构名的时间（±0.2s）。
- 拆镜点优先落在句子之间，不落在句子中间。

## 素材镜与排版镜的配比

参考片：排版/数据镜 22 镜（46%），AI 插图 12 镜（25%），3D 物件 12 镜（25%），实拍 2 镜（4%）。

建议配比：
- 排版镜 ≥ 40%：这是"解说片"而非"混剪"的底线。
- 每 3–4 个排版镜之间插 1 个素材镜（AI 插图或实拍），给眼睛休息。
- 素材镜不要超过 8 秒，否则观众会以为在放片。
