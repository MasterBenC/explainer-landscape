# 深度、质感与常驻图层

参考片（金融棒棒糖 CASE 01，4:28）实测：画面填充率 0.77、每帧 22 个文字块、亮度均值 141（暗场 27 / 亮场 222 交替）、平均帧差 16.8、48% 静止帧。

对照我们第一版（填充 0.05、每帧 3 个文字块、亮度 9、帧差 0.46）——差距不在"动效多少"，在**画面里有没有东西**。

## 一、深度交替（最重要）

同一部片子里交替使用两种构图，不要全片一个样：

| 模式 | `depth` | 画面 | 用在哪 |
|---|---|---|---|
| 背景铺满 | `bg` | 图铺满全幅 + 左侧渐深蒙版 + 文字压在上面 | 建立场景、情绪段、开篇 |
| 前景浮起 | `fg` | 暗底 + 图片做成一块带投影的档案卡浮在中间，文字压在卡片边缘上 | 细节段、证据段、需要"拿出来看"的内容 |
| 左文右图 | `split` | 左侧实色栏放文字，右侧整幅清晰图，互不覆盖（`split_x` 控制分栏） | 需要图完整可读、又要压标题的证据段 |

实测填充率：`bg` 0.81–0.92，`fg` 0.31–0.34。交替出现就有了节奏，不会一屏一屏都是同样的密度。

```json
{"depth": "bg", "bg": "assets/wx_07.png", "scrim": [0.0, 0.48]}
{"depth": "fg", "bg": "assets/wx_04.png"}
```

## 二、档案化处理（历史感）

"旧"要旧在**素材层**，字必须锐利。参考片的做法就是这样：画面门闪、颗粒、划痕，字幕和标签一动不动。

`archival` 参数（作用在图片层，后画的文字不受影响）：

| 参数 | 默认 | 含义 |
|---|---|---|
| `desat` | 0.62 | 去饱和比例，0.4–0.7 之间像"旧照片"，1.0 是黑白 |
| `warm` | 1.0 | 暖调倍率，1.03–1.08 有泛黄感 |
| `dark` | 0.0 | 压暗，0.05–0.12 适合亮度高的资料页 |

颗粒用 6 张预生成噪声轮换，混合系数 0.03；门闪靠背景每帧 ±20px 的正弦位移。这两样加起来就是"胶片在走"的感觉，也是静止段不死的来源。

## 三、常驻图层（识别度）

参考片有三层东西从头到尾都在：

1. **左上账号标签**：`金融棒棒糖 · 视频 / CASE 03`，22px 加粗 + 下面 2px 强调色短线
2. **右上标的标签**：`招商银行西安分行 · 3000亿`，30px
3. **下三分之一横条**：80px 高，左边一块强调色标签，中间一句话，右边等宽时间戳

横条是这套风格最强的"电视感"来源。一屏一个事实，横条只写这一屏在讲什么，不要写成完整句子。
三个字段对应关系：`strap`（中间那句话）、`strap_tab`（左边标签）、`clock`（右边时间戳，
贴在横条右端 y=812；只写 `clock` 不写 `strap` 不会画）。

```json
{"label_left": "金融棒棒糖 · 视频 / CASE 03",
 "label_right": "招商银行西安分行 · 3000亿",
 "strap": "贷款 1700 亿，产业债每年 150 亿。", "strap_tab": "资金", "clock": "2026"}
```

## 四、证据标注（callout）

图片来源要指得出来：一条引线 + 一个标签，线先长出来，标签后出现。

```json
{"callouts": [{"x": 0.70, "y": 0.45, "dx": -100, "dy": -70, "text": "光机所 1962"}]}
```

`x/y` 是画面归一化坐标（指向图上那个点），`dx/dy` 是标签相对位移（像素）。

## 五、检查线

改完版式先跑这三条，再看观感：

```bash
python "<skill-dir>/assets/kit/render.py" spec.json out/ --png      # 终帧
python "<skill-dir>/assets/kit/render.py" spec.json out/ --contact  # 拼图：深度是否交替

```

填充率自查（论文级指标，纯 PIL，不需要 numpy）：

```python
from PIL import Image
g = Image.open("out/s01.png").convert("L")
hist = g.histogram()
total = sum(hist)
fill = sum(hist[23:]) / total
bright = sum(i * c for i, c in enumerate(hist)) / total
print(f"fill={fill:.2f}, bright={bright:.1f}")
```

`audit.py spec.json --images out/` 已经把这两项和"强调红占比"一起做了，批量查时不用手写。

目标：`bg` 镜 fill ≥ 0.7，`fg` 镜 0.25–0.4，全片亮度 50–90；低于 40 说明黑得太多，观众会觉得"没做画面"。

## 六、画面不打架的五条（踩过的坑）

1. **背景图里的字必须毁掉。** 文章配图、信息图自带大量文字，铺满当背景会和我们叠的字抢注意力——观众看到的是一屏乱码。做法不是"加点模糊"，是**先降采样再放大**（1920 宽降到 1/100，再插值回原尺寸），最后再补一层小半径模糊。模糊半径再大也杀不掉 200px 的大字，降采样可以。
2. **一张图只当一层用。** 同一张图既做背景又做前景卡片，两层文字必然重叠。背景镜就不要再画卡片，前景镜就不要铺背景。
3. **前景卡片也要软化。** 卡片是"档案文件"，不是"要读的文件"：降采样 + 8px 模糊 + 20% 压暗，留形不留字。
4. **转场不要交叉叠字。** 叠化和划像会让上一个镜头的标题和下一个镜头的标题同时出现几帧，看起来就是"字糊在一起"。默认统一走**黑场过渡**（0.3–0.4s），只在纯画面镜之间用叠化。
5. **颗粒和缓推要静。** 逐帧随机颗粒 = 电视雪花，整片都在跳；正确做法是**每个镜头固定一种颗粒**，只在切镜时换。缓推幅度 0.010–0.012 就够，再大会有重采样的抖动感。
   缓推走 scene 级 `camera` 字段，**默认 0（关）**，只给"有图当底"的镜头开；纯排版镜（文字卡）不要开——字号会被重采样啃掉一圈。背景图本身另有一套 ±14px 的极缓平移，不用你手调。
