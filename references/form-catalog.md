# 八种版式

每种版式都是一个"信息动作"，不是装饰。选错版式，观众会觉得"讲不动"。

前六种（1–6）是"说不清的东西用文字结构讲清"；后两种（7–8）是"能画出来的东西不要用嘴说"：数据用 `chart` 直接画，现场用 `photo` 直接看。

---

## 1. `bignum` 巨数字卡

一个数字承担整屏。用在：转折点、量级对比、时间跨度。

```
┌────────────────────────────────────────────────────────────┐
│  章节牌                                                    │
│  日期                                                      │
│  相对时间                                                  │
│                                                            │
│      17年                    ← display 150–180，白或红      │
│      ─────────────                                          │
│      他亲手创立、干了三十三年   ← H3 42，muted               │
│                                                            │
│                        董事会 11 席（含黄仁勋本人） ← sub 21 │
│                                                            │
│  来源：…                                        TC 00:33.0 │
└────────────────────────────────────────────────────────────┘
```

槽位：`number`（必须带单位，中文数字与阿拉伯数字不混用）、`unit`（可选，跟在数字后小一号）、`caption`（一句解释，≤18 字）、`note`（右下角出处或补充，≤24 字）。

规则：
- 数字与单位字号比 6:1。
- 红色只给"结果"数字，别给过程数字。
- 一次只推进一个数字；两个数字要对比时用 `timeline`。

---

## 2. `evidence` 双栏证据

左画面（人/场景），右证据（新闻页、推文、官网、公告）。用在：每一处"据报道""声明说"。

```
┌────────────────────────────────────────────────────────────┐
│  章节牌                                       品牌水印      │
│  日期                                                      │
│  ┌──────────────────┐   ┌──────────────────────────────┐   │
│  │                  │   │  ┌────────────────────────┐  │   │
│  │   实拍 / AI 画面   │   │  │  截图（新闻页/推文）      │  │   │
│  │   或人物抠像       │   │  │  带 1px 描边 + 投影      │  │   │
│  │                  │   │  └────────────────────────┘  │   │
│  │                  │   │  标题 42                    │   │
│  │                  │   │  机构·日期 24 muted          │   │
│  └──────────────────┘   └──────────────────────────────┘   │
│  来源：画面 CNBC（2026-11-09）；截图 纽约时报（2026-11-11）  │
└────────────────────────────────────────────────────────────┘
```

槽位：`left`（图片路径或纯色占位）、`right`（截图路径）、`attrib`（机构 + 日期）、`quote`（可选，截图里被引用的那行原文，42px）。

规则：
- 截图必须可读；读不清就裁到关键块，不要整体缩小。
- 左右不要等宽：左 46%、右 44%，中间留 60px 呼吸。
- 截图不做倾斜，不做边框装饰。

## 3. `list` 逐条揭示

左标题 + 条目，右侧配图。用在：三个原因、三条线索、三个疑点。

```
┌────────────────────────────────────────────────────────────┐
│  主标题（一屏一句）                                         │
│                                                            │
│  01  第一，反对放开算力出口      ← 30px，编号 accent         │
│  02  第二，自己已经在做芯片                                  │
│  03  第三，不那么需要英伟达了                                │
│                                                            │
│                                      ┌──────────────────┐  │
│                                      │   配图 / 数据图    │  │
│                                      └──────────────────┘  │
└────────────────────────────────────────────────────────────┘
```

槽位：`items[]`，每条 `{n, text, at}`；`at` 是这条出现的秒数（相对本镜）。`media` 可选。

规则：
- 3–4 条最佳；2 条显单薄，5 条以上要拆。
- 逐条出现间隔 1.2–2.4 秒，和旁白念到那条的时间对齐。
- 已经在讲的条目降低不透明度到 0.55，当前条目全白并带 accent 竖线。

## 4. `timeline` 时间轴对比

用在：前后变化、因果顺序、事件流。

```
┌────────────────────────────────────────────────────────────┐
│  英伟达联邦游说                                             │
│                                                            │
│   2024 ●───────────────  约 $600 万                         │
│         ╲                                                  │
│          ╲   ×10                                            │
│           ╲                                                │
│   2025 ●───────────────  $2500 万                           │
│                                                            │
│  来源：POGO、Bloomberg（2026-11）                            │
└────────────────────────────────────────────────────────────┘
```

槽位：`points[]`，每个 `{label, value, at}`；`delta`（可选，写在两点之间）；`axis`（横/纵）。

规则：
- 最多 4 个点；点之间用细线，不用箭头装饰。
- 数值变化用 accent 标注倍数或差值。
- 时间从左到右或从上到下，不要混。

## 5. `relation` 关系图

用在："谁在背后""谁得利""谁和谁是一伙的"。

```
┌────────────────────────────────────────────────────────────┐
│  背后的推手，到底有谁？                                      │
│                                                            │
│              民主党                  鹰派                    │
│                 ╲                   ╱                       │
│                  ╲                 ╱                        │
│                   ●─── 黄仁勋 ───●                          │
│                  ╱                 ╲                        │
│              华尔街                两届政府的人               │
│                                                            │
│  中间节点 30px 白底黑字；外圈 24px muted；连线 1px line       │
└────────────────────────────────────────────────────────────┘
```

槽位：`center`（中心节点，≤8 字）、`satellites[]`（3–5 个，`{label, at}`）。`satellites` 可带 `kind`（`person` / `money` / `org`）决定连线颜色。

规则：
- 卫星节点 3–5 个，对称分布，不要连成蜘蛛网。
- 逐条出现，间隔 1.6 秒；中心节点先出。
- 连线动画从中心向外生长，0.3 秒。

## 6. `sources` 结尾来源清单

用来收尾：左侧一句结语，右侧全部出处滚动。这是这类视频"可信度"的落点。

```
┌────────────────────────────────────────────────────────────┐
│                                                            │
│   牌局还没结束。              │  参考报道与资料              │
│   拭目以待                    │  纽约时报：…（2026-11-11）   │
│                              │  华尔街日报：…（2026-11-11） │
│   （H1 88，最多两行）          │  CNBC、Reuters…              │
│                              │  …（13–20 行，21px，1.55 行距）│
│                              │  实拍、图片与音乐             │
│                              │  音乐："Under Suspicion"     │
└────────────────────────────────────────────────────────────┘
```

槽位：`closing`（≤14 字 ×2 行）、`blocks[]`（每组 `{title, lines[]}`）。

规则：
- 来源区从 y=90 起，逐行 21px，行距 1.55，最多 20 行；超出就滚动（每 4 秒上移一组）。
- 结语区和来源区之间一条 1px 竖线分隔，位置 x=1180。
- 结语不带标点收尾（原片用的是"拭目以待"这种短句）。

## 7. `chart` 数据图

**数据自己会说话时，不要把数字塞回句子。** 这是数据叙事的主力：左栏照常是标题 + 副题，右栏 900–1780 直接画图，观众一眼看到量级差。

```
┌────────────────────────────────────────────────────────────┐
│  越跳越快                       每次跨越用时（年）           │
│  ─────────                     ┌──────────────────────┐    │
│  从 1000 亿到 3000 亿，          │  ▇▇▇▇▇  19           │    │
│  用时 19 年 → 7 年 → 4 年        │  ▇▇  7               │    │
│                                │  ▇  4   ← 强调红       │    │
│                                └──────────────────────┘    │
│                                  单位：年                    │
└────────────────────────────────────────────────────────────┘
```

槽位：`kind`（`bar` / `line` / `donut` / `kpi`）、`data[]`（每项 `{name, label, value, highlight?}`）、`chart_title`、`source_note`。

四种画法各管一件事：

| kind | 用在 | 数据怎么给 |
|---|---|---|
| `bar` | 并列量级对比：三个数谁大谁小 | 每项一个 `value`，最大值自动定标；`highlight:true` 的那根用强调红 |
| `line` | 趋势：逐年在涨还是在跌 | 按时间顺序给 `data[]`，点沿折线依次出现 |
| `donut` | 构成占比：七成 / 四成 / 三成 | 每项 `value` 是百分比或绝对量，总和自动归一 |
| `kpi` | 三个关键指标并排，不比较大小 | `value` 直接给字符串（"≥4500 亿"），可带单位 |

规则：
- 每屏最多一个图，最多 5 根柱 / 6 个点 / 5 段环；再多就拆两镜。
- 数字标注 34px 加粗，轴标签 24px muted，`source_note` 20px 贴右下（1780, 860）。
- `chart_title` 写在图上方 60px 处，28px muted；标题只说单位或口径（"每次跨越用时（年）"），不重复左栏标题。
- `highlight` 一屏只给一个：强调色全片用量 < 2%。
- `value` 为 0 的项不要放进来；`bar` 里长短悬殊时改用 `kpi`，否则小的那根看不见。

## 8. `photo` 图片镜

**有一段真实画面/资料页可看时，用图，别用形容词。** 两种落法：`framed:true` 做右侧卡片（配白底信息图、截图），不加则整幅出血（暗调照片、现场照）。

```
framed（右侧卡片）                    整幅出血
┌──────────────────────────────┐   ┌──────────────────────────────┐
│ 一张卡，三十年      ┌────────┐ │   │▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓│
│ ─────────          │        │ │   │▓▓▓  压暗带（scrim 0.46）  ▓▓│
│ 1996 年，解放路，    │  图片  │ │   │▓▓  松林：首个科技金融展厅  ▓│
│ 第一张一卡通         │        │ │   │▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓│
│                    └────────┘ │   │                              │
│ 图：金融棒棒糖·图说             │   │ 图：金融棒棒糖·图说           │
└──────────────────────────────┘   └──────────────────────────────┘
```

槽位：`image`（本地路径；相对 spec 文件解析）、`caption`、`credit`、`framed`、`scrim`。

规则：
- `framed:true` 时卡片固定 900–1786 × 300–800，caption 在左栏 y=640 / 30px，credit 在 (900, 818) / 20px；图片上方压 70/255 的黑，让卡片里的白底不刺眼。
- 整幅出血时，顶部按 `scrim`（默认 0.46）压一条暗带，caption 30–32px 放在 y=700 带内，credit 20px 在 y=840；正文绝不能压在亮部。
- 一张图只讲一件事；caption 写"这是什么 + 什么时候"，不写评论。
- `credit` 必须能追到机构 + 日期，不允许写"网络"。
- 同一张图不要连续用两镜；配合 `depth:"fg"` 时图片走前景卡，与 `bg` 铺底交替，避免全片一个密度。
